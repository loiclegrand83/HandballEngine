# Memlog — Dock UI PRD

## Decisions

| Type | Text | Owner |
|------|------|-------|
| decision | Multi-surface design: dock + sidebar system to replace flat 280px sidebar clutter. | Loic |
| decision | Dock placement: **bottom (horizontal)** on both tablet and desktop for visual consistency. | Loic |
| decision | Sidebar structure: hierarchical collapsible menus (Vue, Exercice, Autres) with default state = **collapsed**. | Loic |
| decision | Icon set: custom-designed, realistic Handball Engine icons (not generic reuse). | Loic |
| decision | Responsive breakpoints: ≤1024px (tablet, 120px sidebar), 1025–1399px (desktop compact, 180px), ≥1400px (desktop wide, 220px). | UX Agent |
| decision | Dock sizing: 64px height (bottom bar), icon 24–32px, button area 48×48px (touch-friendly). | UX Agent |
| decision | Animation: collapsible sections slide/fade 0.15s ease; no heavy animations. | UX Agent |
